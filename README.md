# Workbench V0.4.2

Interactive design-workbench prototype, updated for the September 17, 2026 PRD review.

## Preview

https://tiyatian.github.io/workbench-prototype/

Includes Create, Assets, Gallery, Deliverables, Project, the shared 2D/3D canvas, local Design System editing, and local material/project persistence.

## Demo Boundaries

- Files, projects, design systems, and feedback stay in the visitor's browser (IndexedDB); they are not uploaded to this repository or a shared backend.
- Opening this site on another device does not synchronize your saved content.
- AI generation and Skill execution are not connected. Prebuilt generation demos are explicitly marked.
- Image/PDF basic extraction runs locally. Website fetching and AI analysis require a separate backend and are unavailable on GitHub Pages.
- Account details are sample UI, not a real authentication or billing service.
- The new DS consolidated preview and multi-category immersive transitions are deferred.

This repository contains only static frontend files and bundled demo assets, not local server code, API credentials, or product-planning documents.
